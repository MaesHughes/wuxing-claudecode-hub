# /test

Smart test runner that finds and runs tests based on your project setup.

## Usage

```
/test
```

This command will:
1. Detect your test framework (Jest, Vitest, Mocha, etc.)
2. Find relevant test files
3. Run the tests
4. Display results in a clean format

## Features

- Automatic test framework detection
- Smart test file discovery
- Formatted test results
- Failed test summary
